# Repository guide

Start with the [root README](../README.md) for setup and a project overview. This guide explains where to find the remaining material.

| Location | Contents |
|---|---|
| [`../frontend/`](../frontend/) | Student and teacher React application; see its README for setup and UI details. |
| [`../webapi/`](../webapi/) | HTTP server and API services. |
| [`../engine/`](../engine/) | Lesson engine, grading, routing, state, safety, model integration, and theme generation. |
| [`../diagnostic/`](../diagnostic/) | Readiness quest, assessment, placement, and its own README. |
| [`../projects/`](../projects/) | Project catalog and authored lesson content, checks, hints, and reference material. |
| [`../evaluation/`](../evaluation/) | Evaluation plan, harnesses, synthetic data, console, and result reports. |
| [`../tests/`](../tests/) | Backend tests. |
| [`../config/`](../config/) | Bedrock Guardrail configuration. |
| [`curriculum/`](curriculum/) | CSTA standards JSON and source workbook. |
| [`rubric/`](rubric/) | Original vision, technical and learning-trajectory reference materials and standards CSV. |
| [`frontend-notes/`](frontend-notes/) | Frontend gaps and adaptive-path API handoff notes. |
| [`weather-station-project/`](weather-station-project/) | Original Weather Station project specification. |
| [`../.kiro/specs/weather-station-adaptive-lesson/`](../.kiro/specs/weather-station-adaptive-lesson/) | Detailed Weather Station requirements and design. |
| [`resources/`](resources/) | Summaries of Code.org architecture and concept learning trajectories. |
| [`archive/prototype-reference.md`](archive/prototype-reference.md) | Previous root README, preserved for detailed historical notes; verify against current code. |

Documentation and reference folders have been consolidated here; application code and authored projects remain at the repository root. The file [`must familiarise/README.md`](must%20familiarise/README.md) contains an older note about reference files; the corresponding upstream vision and technical documents are already present under `rubric/`.
